# Как слышать звук при использовании Virtual Cable

## Проблема
При использовании CABLE Input как устройства по умолчанию, весь звук идет в виртуальный кабель, и вы ничего не слышите в наушниках.

## Решение 1: Функция "Прослушать" (рекомендуется)

1. **Откройте настройки звука:**
   - Правый клик на значок звука → "Звуки"
   - Вкладка "Запись"

2. **Найдите CABLE Output:**
   - Правый клик → "Свойства"
   - Перейдите на вкладку "Прослушать"

3. **Включите прослушивание:**
   - ✓ Поставьте галочку "Прослушивать с данного устройства"
   - В выпадающем списке выберите ваши наушники/колонки
   - Нажмите "Применить"

Теперь звук будет одновременно:
- Идти в CABLE для записи в AI Meetings
- Дублироваться в ваши наушники

## Решение 2: VoiceMeeter (продвинутое)

VoiceMeeter - бесплатный виртуальный микшер, который позволяет направлять звук в несколько устройств одновременно.

1. **Скачайте VoiceMeeter Banana:**
   - https://vb-audio.com/Voicemeeter/banana.htm
   - Установите и перезагрузите компьютер

2. **Настройте VoiceMeeter:**
   - Сделайте "VoiceMeeter Input" устройством по умолчанию
   - В VoiceMeeter настройте:
     - Hardware Out A1: Ваши наушники
     - Hardware Out A2: CABLE Input
   - Включите кнопки A1 и A2 для основного канала

3. **В AI Meetings:**
   - Выберите CABLE Output как устройство ввода

## Решение 3: Audio Router для конкретных приложений

Используйте Audio Router или EarTrumpet для направления звука конкретных приложений:

1. **EarTrumpet** (из Microsoft Store):
   - Позволяет выбрать устройство вывода для каждого приложения
   - Можно направить браузер в CABLE, а остальное в наушники

2. **Настройка:**
   - Системные звуки → Наушники
   - Chrome/Firefox → CABLE Input
   - В AI Meetings записывайте с CABLE Output

## Решение 4: OBS Studio Virtual Audio

1. **Установите OBS Studio**
2. **Добавьте источники:**
   - Захват звука рабочего стола
   - Настройте мониторинг → "Мониторинг и вывод"
3. **Используйте виртуальный выход OBS**

## Быстрая инструкция для Virtual Cable:

```
Настройки Windows:
1. Устройство по умолчанию: CABLE Input
2. Запись → CABLE Output → Свойства → Прослушать
3. ✓ Прослушивать с данного устройства
4. Выберите: Ваши наушники

AI Meetings:
- Устройство ввода: CABLE Output
- Начать запись

Результат:
- Звук записывается ✓
- Вы слышите звук в наушниках ✓
```

## Возможные проблемы:

**Задержка звука:**
- В свойствах CABLE Output → Дополнительно
- Выберите минимальное качество (16 бит, 44100 Гц)
- Это уменьшит задержку

**Эхо или двойной звук:**
- Убедитесь, что в AI Meetings НЕ включен мониторинг
- Проверьте, что прослушивание включено только в одном месте

**Низкое качество:**
- В свойствах CABLE → Дополнительно
- Выберите качество CD или выше
