# Решение проблемы "Digital filter critical frequencies"

## Проблема
При запуске приложения возникает ошибка:
```
Digital filter critical frequencies must be 0 < Wn < 1
```

## Причина
Эта ошибка возникает в модуле `audio_synchronizer.py` при создании цифровых фильтров с помощью `scipy.signal.butter`. Проблема возникает когда:
- Частота фильтра слишком близка к 0
- Частота фильтра слишком близка к частоте Найквиста (половина частоты дискретизации)
- Нормализованная частота выходит за пределы (0, 1)

## Решение

### Быстрое решение
Запустите тестовый скрипт для проверки:
```bash
python test_startup.py
```

Если тест проходит успешно, запускайте основное приложение:
```bash
python main.py
```

### Что было исправлено
1. Добавлена проверка и корректировка частот фильтров в `audio_synchronizer.py`
2. Добавлена обработка ошибок при создании фильтров
3. Если фильтры не могут быть созданы, аудио обрабатывается без фильтрации

### Детали исправления
В классе `EnhancedAudioProcessor` метод `_create_filters` теперь:
- Проверяет, что частоты находятся в допустимом диапазоне
- Нормализует частоты относительно частоты Найквиста
- Обрабатывает исключения при создании фильтров
- Создает заглушки, если фильтры не могут быть созданы

## Если проблема сохраняется

### 1. Проверьте версию scipy
```bash
pip show scipy
```

Убедитесь, что версия >= 1.8.0

### 2. Переустановите scipy
```bash
pip uninstall scipy
pip install scipy>=1.8.0
```

### 3. Отключите фильтрацию (временное решение)
Если проблема критична, можно временно отключить аудио фильтры, закомментировав их использование в `audio_synchronizer.py`

## Техническая информация
Фильтры Баттерворта требуют, чтобы нормализованная частота среза (Wn) находилась в интервале (0, 1), где:
- 0 соответствует 0 Hz
- 1 соответствует частоте Найквиста (sample_rate / 2)

Для частоты дискретизации 16000 Hz:
- Частота Найквиста = 8000 Hz
- Фильтр высоких частот: 80 Hz → Wn = 80/8000 = 0.01
- Фильтр низких частот: 8000 Hz → Wn = 8000/8000 = 1.0 (корректируется до 0.99)
