# Решение проблемы "No module named 'comtypes'"

## Проблема
При запуске приложения возникает ошибка:
```
Windows audio capture not available: No module named 'comtypes'
```

## Причина
Модуль `comtypes` необходим для работы с Windows Audio API (WASAPI) и захвата системного звука в Windows. Без него приложение работает, но без возможности записи звука с наушников/колонок.

## Решение

### Быстрое решение
Запустите один из установочных скриптов:

```bash
# Минимальная установка (рекомендуется)
minimal_install.bat

# Или полная установка
pip install -r requirements.txt
```

### Ручная установка
Если скрипты не работают, установите вручную:

```bash
pip install comtypes
```

### Проверка установки
После установки проверьте все зависимости:

```bash
python check_dependencies.py
```

## Дополнительная информация

### Что делает comtypes?
- Позволяет захватывать звук с устройств вывода (наушники, колонки)
- Обеспечивает работу режима "Windows WASAPI" в приложении
- Необходим для записи системного звука без Stereo Mix

### Если comtypes не устанавливается
1. Убедитесь, что у вас установлен Python 3.8 или выше
2. Обновите pip: `python -m pip install --upgrade pip`
3. Попробуйте установить через системный Python: `py -m pip install comtypes`

### Работа без comtypes
Приложение может работать без comtypes, но с ограничениями:
- Будет доступна только запись с микрофона
- Запись системного звука будет недоступна
- Режим Windows WASAPI не будет работать

## Связанные файлы
- `src/windows_audio_capture.py` - модуль для работы с Windows Audio
- `minimal_install.bat` - скрипт минимальной установки
- `requirements.txt` - полный список зависимостей
- `check_dependencies.py` - проверка установленных модулей
