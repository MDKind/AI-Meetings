# Настройка захвата системного звука в Windows

## Проблема
Приложение записывает только звук с микрофона, но не записывает звук из других источников (YouTube, музыка, звонки и т.д.).

## Решения

### Способ 1: Включить Stereo Mix (Стереомикшер)

1. **Откройте настройки звука Windows:**
   - Правый клик на значок звука в трее → "Звуки"
   - Или: Панель управления → Звук

2. **Перейдите на вкладку "Запись"**

3. **Включите Stereo Mix:**
   - Правый клик на пустом месте → "Показать отключенные устройства"
   - Найдите "Stereo Mix" или "Стереомикшер"
   - Правый клик → "Включить"
   - Правый клик → "Использовать по умолчанию"

4. **В приложении AI Meetings:**
   - В поле "Устройство ввода" выберите "Stereo Mix" или "Стереомикшер"
   - Нажмите "Начать запись"

### Способ 2: Использовать режим Windows WASAPI

1. **В приложении AI Meetings:**
   - Выберите режим записи: "Улучшенный (Windows WASAPI)"
   - В поле "Устройство вывода" выберите ваши наушники/колонки
   - Нажмите "Начать запись"

### Способ 3: Установить Virtual Audio Cable

1. **Скачайте и установите VB-Audio Virtual Cable:**
   - Сайт: https://vb-audio.com/Cable/
   - Скачайте и установите бесплатную версию

2. **Настройте Windows:**
   - В настройках звука установите "CABLE Input" как устройство воспроизведения по умолчанию
   - В приложениях (браузер, плеер) звук будет идти в виртуальный кабель

3. **В приложении AI Meetings:**
   - В поле "Устройство ввода" выберите "CABLE Output"
   - Нажмите "Начать запись"

4. **Чтобы слышать звук самому:**
   - Откройте настройки звука → вкладка "Запись"
   - Найдите "CABLE Output" → Свойства → Прослушать
   - Поставьте галочку "Прослушивать с данного устройства"
   - Выберите ваши наушники/колонки

## Проверка работы

1. **Запустите приложение:**
   ```bash
   python main.py
   ```

2. **Выберите правильное устройство:**
   - Для записи системного звука: Stereo Mix, CABLE Output или аналог
   - Для записи микрофона: ваш микрофон

3. **Включите что-нибудь со звуком:**
   - YouTube видео
   - Музыку
   - Любое приложение со звуком

4. **Проверьте индикатор уровня звука в приложении**

## Если ничего не работает

### Проверьте драйверы звуковой карты
Некоторые современные драйверы отключают Stereo Mix. Попробуйте:
- Установить более старую версию драйвера
- Использовать универсальный драйвер Windows

### Используйте OBS Studio Virtual Audio
1. Установите OBS Studio
2. Установите плагин Virtual Audio Cable для OBS
3. Настройте захват звука в OBS
4. Используйте виртуальное устройство OBS в AI Meetings

### Альтернативные решения
- **Audacity** - может записывать системный звук через WASAPI
- **VoiceMeeter** - продвинутый виртуальный микшер
- **BlackHole** (для macOS)
- **PulseAudio** (для Linux)

## Режимы записи в AI Meetings

- **Стандартный режим** - использует Stereo Mix (если доступен)
- **Улучшенный режим** - использует Windows WASAPI (требует comtypes)
- **Прямой захват** - пытается захватить звук напрямую с устройства
- **Универсальный режим** - автоматически выбирает лучший метод

## Одновременная запись микрофона и системного звука

Для записи обоих источников:
1. В "Устройство ввода" выберите микрофон
2. В "Устройство вывода" выберите наушники/колонки
3. Используйте "Улучшенный" или "Универсальный" режим
