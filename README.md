# AI MEETINGS - Аудио-ассистент для встреч

Проект для обработки аудио в реальном времени с интеграцией ChatGPT для быстрых ответов на вопросы и создания саммари встреч.

## Возможности

- Захват аудио с наушников/микрофона в реальном времени
- Распознавание речи с помощью Whisper от OpenAI
- Интеграция с ChatGPT API для ответов на вопросы
- Формирование саммари встреч
- Пользовательский интерфейс для управления системой
- Сохранение и загрузка истории разговоров

## Требования

- Python 3.8+
- Библиотеки, указанные в `requirements.txt`
- API ключ OpenAI
- Микрофон или наушники с микрофоном

## Установка

1. Клонируйте репозиторий или создайте структуру проекта с помощью скрипта:

```powershell
# PowerShell
.\create_project_structure.ps1
```

2. Создайте и активируйте виртуальное окружение Python:

```bash
# Создание виртуального окружения
python -m venv venv

# Активация в Windows
venv\Scripts\activate

# Активация в Linux/Mac
source venv/bin/activate
```

3. Установите зависимости:

```bash
pip install -r requirements.txt
```

4. Создайте файл `.env` в корневой директории проекта и добавьте ваш API ключ OpenAI:

```
OPENAI_API_KEY=your_api_key_here
```

## Запуск приложения

```bash
python main.py
```

## Использование

1. Выберите устройство ввода (микрофон или наушники) из выпадающего списка.
2. Выберите модель Whisper для распознавания речи (для быстрого старта рекомендуется `tiny` или `base`).
3. Выберите язык распознавания (`ru` для русского, `en` для английского, `auto` для автоопределения).
4. Выберите модель ChatGPT (`gpt-4o` рекомендуется для лучшего качества).
5. Нажмите кнопку "Начать запись" для начала захвата и обработки аудио.
6. Говорите в микрофон, система автоматически распознает речь и отправит её в ChatGPT.
7. Ответы ChatGPT будут отображаться на соответствующей вкладке.
8. Нажмите "Сгенерировать саммари" для создания резюме встречи.
9. Используйте кнопки "Сохранить разговор" и "Загрузить разговор" для работы с историей.

## Возможные проблемы и их решение

### Не удается инициализировать PyAudio

Если при запуске возникает ошибка с PyAudio, попробуйте следующее:

- Windows: `pip install pipwin && pipwin install pyaudio`
- Linux: `sudo apt-get install python3-pyaudio` или `sudo apt-get install portaudio19-dev && pip install pyaudio`
- macOS: `brew install portaudio && pip install pyaudio`

### Ошибка при загрузке модели Whisper

Для работы с моделями Whisper требуется достаточное количество оперативной памяти:
- `tiny`: ~1 GB
- `base`: ~1 GB
- `small`: ~2 GB
- `medium`: ~5 GB
- `large`: ~10 GB

Если возникают проблемы, используйте модели меньшего размера.

### Проблемы с API ключом OpenAI

- Убедитесь, что ваш API ключ активен и имеет достаточно средств.
- Проверьте, что файл `.env` находится в корневой директории проекта.
- Перезапустите приложение после изменения файла `.env`.
